Download srb2_3ds_old3ds_arid canyon(single player) or srb2_3ds_old3ds_multiplayer (for multiplyaaer only) from the latest release on Github and extract it.
If you would like to use the .3dsx file, copy it to /3ds/srb2_3ds on your SD card. If you would like to use the .CIA file, you may copy it at any location on your SD card.
Download SRB2's assets: file1(https://github.com/mazmazz/SRB2/releases/download/SRB2_assets/SRB2-v2122-assets.7z) and file2(https://github.com/mazmazz/SRB2/releases/download/SRB2_assets/SRB2-v2122-optional-assets.7z) and extract them to /3ds/srb2 on your SD card. (Note: make sure any existing config.cfg file is located in the same directory as the game files.)
Make sure you have dumped your DSP firmware and dspfirm.cdc is present. If it isn't: install and run the "dspDump" homebrew first.
